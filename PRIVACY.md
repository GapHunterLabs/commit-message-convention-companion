# Privacy Policy — Commit Message Convention Companion

**Effective date:** 2026-08-19

Commit Message Convention Companion is a Gap Hunter Labs plugin for
IntelliJ Platform IDEs. This policy is short because the plugin's design
makes it short: there is nothing to disclose beyond what's below.

## What this plugin collects

**Nothing.** Commit Message Convention Companion does not collect,
store, transmit, or sell any data — no source code, no file contents,
no file paths, no commit message text, no usage analytics, no
telemetry, no crash reports, no personally identifiable information.
The commit message you are writing exists only in memory for as long
as it takes to validate it against Conventional Commits, right before
you press Commit.

## Network access

**None.** Commit Message Convention Companion makes zero network calls
during normal operation. Every check is computed directly from the
commit message text already present in the VCS Commit dialog — no
external service, no telemetry endpoint, ever.

## Third parties

None. Commit Message Convention Companion has no third-party SDKs, no
analytics libraries, no ad networks, no external dependencies that
phone home.

## Changes to this policy

If this ever changes, this file will be updated and the change will be
noted in the plugin's `CHANGELOG.md`.
